# Changelog

## 0.1.0

- First version: reference tree for SOLIDWORKS assemblies, parts and drawings, read with the SOLIDWORKS Document Manager or a raw file scan.
- Shows stored path, resolved path and how the file was found, flags missing files, files found elsewhere, several files with the same name and name clashes with files loaded earlier.
- List of file names referenced with different paths, "Problems only" filter, CSV export.
- GitHub Actions build that uploads the program on every push to `main`.
